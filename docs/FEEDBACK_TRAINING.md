# Bonus: how the feedback would improve the app

**What we save.** Every time a user presses 👍 or 👎, we save three things together:
what they were shown (a story, a coin, a meme or the AI insight), who they are (their coins and investor type),
and whether they liked it. For AI insights we also save the exact question we sent to the AI.

**How it would be used.**
1. **Better AI insights:** see which AI model and which wording get the most 👍, and use those. Later, with many votes,
   teach a model with examples: "users liked answers like this, not like that".
2. **Better news and memes:** learn what each type of user likes (for example, day traders like market stories)
   and show those first.
3. **Check before switching:** try the change on some users first, and keep it only if it gets more 👍.
